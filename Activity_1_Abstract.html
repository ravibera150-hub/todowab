📌 Project Abstract: TaskFlow — Smart To-Do & Focus Task Manager

1. Project Title

TaskFlow — Full-Stack Academic Task Management & Focus Web Application

2. Problem Statement

Students and professionals struggle with daily time management, deadline tracking, and maintaining focus. Existing to-do applications are either too complex or lack real-time countdown alerts, focus timers, and past performance history, leading to missed academic deadlines and low productivity.

3. Proposed Solution

TaskFlow is a modern full-stack web application designed to help users track, organize, and complete daily tasks efficiently. It combines real-time countdown tickers, an interactive Pomodoro focus timer with audio alerts, visual completion statistics, and past-day historical performance tracking.

4. Target Users

  • University students managing coursework, assignments, and exam deadlines.
  • Academic faculty and working professionals seeking daily task organization.
  • Self-learners and developers using Pomodoro focus sessions.

5. Main Features

  • JWT Authentication & Data Security: Secure sign-up, login, and user profile management with password encryption.
  • Task Management (CRUD): Create, read, update, complete, and delete tasks with priority, category, due date, and due time.
  • Real-Time Countdown & Overdue Alerts: Live ticker calculations with urgent alerts for overdue tasks.
  • Pomodoro Focus Timer: 25-minute focus session timer with circular SVG progress, rest intervals, and Web Audio sound alerts.
  • Past-Days Performance History: Historical performance browser with date selection, completion rates, and read-only record safety.
  • Dark & Light Appearance Themes: Custom CSS color palette with instant theme toggling.

6. Technologies Used

  • Frontend: HTML5, Custom Vanilla CSS (Design Tokens, Glassmorphism, CSS Variables), React.js (v18+), Vite, Lucide React Icons.
  • Backend: Node.js, Express.js REST API, JSON Web Token (JWT), bcryptjs password hashing.
  • Audio API: In-browser Web Audio API for sound generation.

7. Database Used

  • MongoDB Atlas & Mongoose ODM: Cloud NoSQL database with schema validation, indexing, and foreign-key user references (with local JSON fallback).

8. Frontend and Backend Architecture

  • Architecture Pattern: Client-Server Single Page Application (SPA) RESTful Architecture.
  • Frontend Layer: Modular React components (Navbar, TaskCard, TaskForm, StatsWidget, PomodoroModal) powered by React Context API (AuthContext, TaskContext, ThemeContext).
  • Backend Layer: Express.js router, controller modules (authController, taskController), JWT authentication middleware, and database access layer (db.js).

9. Expected Outcome

A fully operational, responsive, secure, and cloud-deployed web application accessible on desktop, tablet, and mobile devices, helping users boost productivity by completing 100% of their daily academic tasks on time.
