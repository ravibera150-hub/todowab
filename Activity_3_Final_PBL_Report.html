3. Abstract

TaskFlow is a modern, responsive full-stack task management web application designed to empower students and professionals to organize daily tasks, track deadlines, and improve productivity. Built using React.js, Node.js, Express.js, and MongoDB, the system provides real-time deadline tickers, an interactive Pomodoro focus session timer with Web Audio sound synthesis, visual progress widgets, and past-days performance history tracking. The application implements secure JWT user authentication, password encryption, and a custom CSS design system supporting instant Dark/Light theme toggling.

---

4. Introduction

In modern academic environments, students manage multiple assignments, lab submissions, and exam schedules simultaneously. Traditional paper notes and simple static to-do lists fail to notify users of impending deadlines or assist them in maintaining focused work sessions. TaskFlow bridges this gap by combining task CRUD management with real-time urgency detection, Pomodoro focus tracking, and performance analytics within a clean, cloud-deployed web interface.

---

5. Problem Definition

Students encounter significant time-management challenges: 1. Missed Deadlines: Lack of real-time countdown tickers leads to overdue assignments. 2. Distractions During Study: Difficulty maintaining uninterrupted study blocks. 3. Lack of Performance Insights: Inability to review past days' completed vs. missed tasks. 4. Poor Mobile Usability: Existing web interfaces fail on smartphone screens.

8. Database Design

Mongoose Schemas

1. User Collection (User.js)

  • _id: ObjectId (Primary Key)
  • name: String (Required)
  • email: String (Required, Unique, Indexed)
  • password: String (Hashed password string)
  • createdAt: Date (Auto-timestamp)

2. Task Collection (Task.js)

  • _id: ObjectId (Primary Key)
  • userId: ObjectId (Foreign Key referencing User, Indexed)
  • title: String (Required)
  • description: String
  • priority: Enum ("Low", "Medium", "High")
  • category: Enum ("Work", "Study", "Personal", "Health", "Urgent", "General")
  • dueDate: String (YYYY-MM-DD)
  • dueTime: String (HH:MM)
  • targetDate: String (YYYY-MM-DD)
  • isCompleted: Boolean (Default: false)
  • pomodoroMinutes: Number (Default: 0)
  • createdAt: Date

9. UI/Wireframe Design

  • Header / Navbar: Sticky header containing brand logo, page navigation tabs, task count warning badge, dark/light theme toggle button, user avatar, and mobile drawer overlay.
  • Dashboard View: Welcome header, real-time metrics grid (Total, Completed, Pending, Success Rate), completion progress bar, filter/search controls, task list, and Pomodoro focus timer modal.
  • Pending Tasks View: View dedicated exclusively to incomplete tasks for the day.
  • History View: Two-column browser featuring a past-date picker, history metrics, and read-only task cards.
  • Auth Views: Glassmorphic Login and Signup cards with demo credential quick-fill helpers.

---

10. Module-wise Implementation

1. User Authentication Module: Express auth controller managing signup, password hashing, login, and profile fetching. 2. Task CRUD Module: Complete API endpoints for creating, reading, updating, and deleting tasks scoped strictly to req.user._id. 3. Timer Ticker Engine Module: React TaskContext maintaining a live 30-second interval ticker for dynamic urgency calculation. 4. Pomodoro Focus Module: Circular SVG progress ring (strokeDashoffset) managing 25-min focus / 5-min break cycles with audio chimes. 5. Past Performance Module: Backend aggregation matching targetDate queries and serving historical completed/missed summaries.

11. API Documentation

| Method | Endpoint | Description | Request Body | Auth | | :--- | :--- | :--- | :--- | :---: | | POST | /api/auth/signup | Register new user account | { name, email, password } | ❌ No | | POST | /api/auth/login | Authenticate user & receive JWT token | { email, password } | ❌ No | | GET | /api/auth/profile | Get current user profile | None | ✅ Yes | | GET | /api/tasks | Get today's tasks | None (?date=YYYY-MM-DD) | ✅ Yes | | GET | /api/tasks/pending | Get incomplete tasks for today | None | ✅ Yes | | GET | /api/tasks/history | Get past date summary or day details | ?date=YYYY-MM-DD optional | ✅ Yes | | GET | /api/tasks/stats | Get aggregate task metrics | None | ✅ Yes | | POST | /api/tasks | Create a new task | { title, priority, category, dueDate, dueTime } | ✅ Yes | | PUT | /api/tasks/:id | Update task fields / completion status | { isCompleted, pomodoroMinutes, ... } | ✅ Yes | | DELETE | /api/tasks/:id | Delete a task | None | ✅ Yes |
