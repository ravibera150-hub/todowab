1. Problem Identification

Students, faculty, and professionals struggle to organize daily academic deadlines, assignments, and study routines. Existing web to-do tools lack real-time countdown alerts, focus timers, and past performance records, leading to poor time management and missed targets.

---

2. Requirements Analysis

Functional Requirements

  • User Authentication: Sign up, log in, secure JWT stateless authentication, and user profile management.
  • Task CRUD Operations: Add, edit, delete, mark complete, set priority (High/Medium/Low), and tag categories (Work/Study/Personal/Health/Urgent/General).
  • Real-Time Timers: Automatic countdown ticker calculation with overdue task banners.
  • Pomodoro Focus Timer: 25-minute focus session with rest intervals and Web Audio alerts.
  • Past Days History: Historical task records, date selector, completion rates, and read-only safety.
  • Theme Switching: Light mode and dark mode theme toggling.

Non-Functional Requirements

  • Responsiveness: 100% responsive across desktop, tablet, and mobile browsers.
  • Security: Hashed passwords (bcryptjs), protected API endpoints, user data isolation (userId foreign keys).
  • Performance: Fast API response (< 50ms) and lightweight bundle (< 300KB).

---

3. System Architecture

TaskFlow follows a modern Client-Server Single Page Application (SPA) RESTful Architecture:
  • Client Tier: React.js frontend rendered in Vite, managing UI state via React Context API (AuthContext, TaskContext, ThemeContext).
  • Application Tier: Node.js runtime executing Express.js web server, routing HTTP requests to controller modules, and securing endpoints with JWT Bearer Token middleware.
  • Database Tier: Cloud MongoDB Atlas database managed via Mongoose ODM schemas (User and Task).

---

4. UI / UX Wireframe Design

  • Custom CSS Tokens: Built without heavy third-party frameworks using 100% Vanilla CSS, CSS variables, glassmorphic cards, and smooth micro-animations.
  • Navigation Bar: Brand logo, page links, task count badge, theme switcher, user avatar, and mobile drawer.
  • Dashboard Layout: Top greeting, 2x2 stat widgets grid, progress bar, search/filter controls, task list cards, and Pomodoro focus modal.

---

5. JavaScript Logic & DOM Manipulation

  • Interactive UI Updates: React virtual DOM re-rendering driven by hooks (useState, useEffect, useContext, useMemo).
  • Live Ticker Calculation: 30-second interval timer calculating exact hours and minutes remaining until task deadlines.
  • Web Audio API: Programmatic sound synthesis (AudioContext) for completion sounds and timer alerts without external assets.

---

6. Database Design (MongoDB Schema)

User Schema (server/models/User.js)

{ "name": "String (Required)", "email": "String (Required, Unique, Indexed)", "password": "String (Hashed with bcryptjs)", "createdAt": "Date" }

Task Schema (server/models/Task.js)

{ "userId": "ObjectId (Ref: User, Indexed)", "title": "String (Required)", "description": "String", "priority": "Enum ['Low', 'Medium', 'High']", "category": "Enum ['Work', 'Study', 'Personal', 'Health', 'Urgent', 'General']", "dueDate": "String (YYYY-MM-DD)", "dueTime": "String (HH:MM)", "targetDate": "String (YYYY-MM-DD)", "isCompleted": "Boolean (Default: false)", "pomodoroMinutes": "Number (Default: 0)", "createdAt": "Date" }

---

7. Backend Implementation (Node.js & Express.js)

  • Modular Directory Structure: Separation of concerns across server.js, routes/, controllers/, middleware/, and models/.
  • Stateless Authentication Middleware (authMiddleware.js): Extracts Authorization: Bearer header, verifies token validity using jsonwebtoken, and populates req.user.

9. Frontend-Backend Integration (Fetch API Client)

A unified API helper module (client/src/services/api.js) wraps native fetch() calls:
  • Automatically injects Authorization: Bearer from localStorage.
  • Parses JSON responses and handles HTTP status error codes (401, 403, 404, 500) gracefully.

---

10. React Components & Custom Hooks

  • Global Context Providers:
- AuthContext: Controls user login, signup, token storage, and session validation. - TaskContext: Controls task CRUD state, filtering, stats, countdown ticker, and active Pomodoro task. - ThemeContext: Toggles between light and dark visual themes.
  • Reusable UI Components: Navbar, TaskCard, TaskForm, TaskList, StatsWidget, FilterBar, PomodoroModal, NotificationBanner, ProtectedRoute.
